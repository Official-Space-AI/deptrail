# PoC — 시간축 판정 코어 검증 (2026-08-07)

본 프로젝트 착수 전, 핵심 아이디어("lockfile의 git 이력을 걸으며 IOC 공격 창과 교차 대조하면 과거 노출을 판정할 수 있다")가 실제로 성립하는지 80줄 스크립트로 검증한 기록이다.

## 재현 방법

```bash
bash poc/make_demo_org.sh                        # 모의 조직(레포 3개) 생성
python3 poc/scan.py poc/demo-org poc/ioc-demo.json
```

## 기대 출력

```
IOC: chalk ['5.6.1'] | 공격 창: 2025-11-24T00:00:00+09:00 ~ 2025-11-26T23:59:59+09:00

[노출] api-server  : chalk@5.6.1을 11/25 14:30에 도입(커밋 ...), 11/28 09:00까지 유지 — 공격 창과 겹침
       전이 경로: express → debug → chalk
       조치: 이 기간 CI/개발자 환경의 시크릿 로테이션 필요
[안전] mobile-app  : chalk 미사용
[안전] web-frontend: 감염 버전을 거치지 않음
```

실행 시간은 3레포 기준 약 3초. 정식 구현(`src/deptrail`)은 여기에 CI 실행 기록 상관분석과 4등급 증거 판정(확정/개연성 높음/가능성 있음/증거 없음)을 더한다.
